# MyFinc

**MyFinc** es una aplicación de finanzas personales creada con Flutter para organizar el dinero de forma sencilla y mantener los datos bajo el control del usuario.

## Funciones

- Administrar cuentas financieras y consultar balances.
- Registrar ingresos, gastos y transferencias.
- Consultar estadísticas y categorías.
- Crear y restaurar copias de seguridad locales.
- Elegir tema claro, oscuro o del sistema.
- Comprobar actualizaciones de Android desde el sistema de versiones de MyFinc.

## Privacidad y almacenamiento

MyFinc utiliza SQLite local como almacenamiento principal. Los archivos JSON de respaldo deben guardarse en un lugar privado y seguro.

## Desarrollo

```bash
flutter pub get
flutter analyze
flutter test
flutter run
```

Para compilar Android:

```bash
flutter build apk
```
